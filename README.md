# FlipWiz

FlipWiz is a resale calculator and decision-support website.

## V1

- Profit calculator
- Break-even / maximum-buy foundation
- Marketplace comparison foundation
- SEO-ready structure
- Responsive landing page
- FlipWiz AI coming-soon waitlist

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push this repository to GitHub and import it into Vercel. Vercel will automatically build and deploy the Next.js app.

## Important

Marketplace fee rates in this prototype are illustrative defaults. Verify current marketplace fees before relying on calculations.
